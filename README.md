# GameKit Factory — Slide 15 free demo

This public repository contains **only** the original offline HTML/CSS/JavaScript browser demo. It does **not** include the premium Godot 4 starter source, any accounts, or API keys.

Play the bilingual Arabic/English 15-puzzle in your browser. No login, ads, tracking, server, or payment API.

The demo uses relative links and can run as a GitHub Pages project site.

Storefront and paid product distribution are not active.
